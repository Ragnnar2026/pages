SOCO DIÁRIO — PWA

Arquivos:
- index.html: aplicação
- manifest.json: configuração PWA
- service-worker.js: funcionamento offline/cache
- icons/icon.svg: ícone

COMO USAR:
1. Publique a pasta inteira em um servidor HTTPS.
2. Abra o endereço no celular.
3. No iPhone, use Compartilhar > Adicionar à Tela de Início.
4. No Android, o navegador poderá oferecer a instalação.

Para adicionar frases, edite o array "frases" dentro do index.html.
